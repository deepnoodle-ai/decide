## Design Context

### Users

Developers apply typed decision models to code trees, JSON datasets, and image
collections. They explore a small sample before committing to a large batch.

### Brand Personality

Playful, curious, informative. The user explicitly requested a fun CLI and
interactive workbench. Friendly language should encourage experimentation.
Operational errors remain precise. Dataset runs default to compact per-item decisions and short summaries;
full machine-readable evidence is available through explicit JSONL or file output.
Newcomers navigate visible menus with arrows and Enter. Shortcuts are optional.

### Aesthetic Direction

A terminal field notebook: warm amber emphasis, restrained green success,
clear tables, generous separation, and source evidence at the center.
Wonton provides native keyboard controls. Adapt to narrow terminals.

### Design Principles

1. Explain the next useful action in empty and error states.
2. Show source identity, model work, and recorded evidence clearly.
3. Make sample experiments quick; distinguish them from full-dataset work.
4. Keep keyboard shortcuts visible and preserve terminal cleanup.
5. Add personality to guidance and success, without hiding errors or limits.
