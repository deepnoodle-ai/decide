A reviewer has the least time for the riskiest lines of a change. Here
decide reads each changed function first, and marks the ones to read
closely.

You need decide [installed](/start/#install-decide), an
[API key](/start/#get-a-key), and a GitHub repository where you can add a
workflow.

## Get the demo

The demo is a small shop repository with one uncommitted change, a refund
fix with problems planted in it:

```sh
git clone --depth 1 https://github.com/deepnoodle-ai/decide
sh decide/demo/setup.sh shop && cd shop
```

## Judge each changed function

`code-risk` asks whether code could cause security or data problems, and
how maintainable it is. `--each function` asks about each function the
diff touches:

<Terminal tape="review-local" title="~/shop" label="decide flags Refunds.Apply and Refunds.Search on risk">
**`Refunds.Apply` and `Refunds.Search` are flagged on risk.** `Apply` no
longer checks a refund against the payment, and `Search` builds SQL from
its input.
</Terminal>

## Run it on each pull request

Add your key as a repository secret named `TYPESAFE_API_KEY`. Then save
this as `.github/workflows/decide.yml`:

```yaml title=".github/workflows/decide.yml" collapse={19-25}
name: decide

on: pull_request

permissions:
  contents: read

jobs:
  code-risk:
    runs-on: ubuntu-latest
    env:
      TYPESAFE_API_KEY: ${{ secrets.TYPESAFE_API_KEY }}
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0 # the base branch, to diff against

      - name: Install decide
        run: |
          base=https://github.com/deepnoodle-ai/decide/releases/latest/download
          curl -fsSLO "$base/decide_linux_amd64.tar.gz"
          curl -fsSLO "$base/checksums.txt"
          sha256sum --check --ignore-missing checksums.txt
          tar -xzf decide_linux_amd64.tar.gz decide
          sudo mv decide /usr/local/bin/

      - uses: actions/cache@v4
        with:
          path: ~/.decide/cache
          key: decide-${{ github.ref }}-${{ github.sha }}
          restore-keys: decide-${{ github.ref }}-

      - name: Judge the changed functions
        if: env.TYPESAFE_API_KEY != ''
        env:
          BASE: ${{ github.base_ref }}
        run: |
          git diff "origin/$BASE...HEAD" |
            decide run code-risk --each function --format github
```

Each flagged function becomes a warning on the pull request. The job
passes either way, so for now the results are advice.

## Block a merge

Add `--fail-on flagged` to the last line, and the job fails when a
function is flagged:

```sh
git diff "origin/$BASE...HEAD" |
  decide run code-risk --each function --format github --fail-on flagged
```

Make the job a required check to block merges on it.

## Check that it works

In the shop repository, run the same check and print the exit code:
