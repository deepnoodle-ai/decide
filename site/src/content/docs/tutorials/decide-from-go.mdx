An agent proposes a file operation. Should your program allow it, send it
to a person, or escalate? Here the model answers one question about the
request, and a policy in your Go code decides.

You need Go 1.27 or later, and a [TypeSafe key](/start/#get-a-key) set as
`TYPESAFE_API_KEY`.

## Create a module

```sh
mkdir gate && cd gate
go mod init example.com/gate
go get github.com/deepnoodle-ai/decide
```

## Write the program

Save this as `main.go`. It is the `gate` example from decide's repository:

<Code code={gate} lang="go" title="main.go" meta={`collapse={1-${gate.split('\n').length}}`} />

The model chooses `read_file`, `delete_file`, or `none`. `none` means the
request is unclear, or the proposed operation doesn't match it.

## Read the policy

Each answer comes with a **confidence** from 0 to 1. The policy compares
it against a threshold for the chosen option:

| Chosen option | Outcome |
| --- | --- |
| `read_file` | allow at 0.60 or more, otherwise escalate |
| `delete_file` | allow at 0.85 or more, review from 0.60, otherwise escalate |
| `none` | escalate |

These thresholds are placeholders. Choose yours from labeled examples of
your own traffic.

## Run it

<Terminal tape="go-gate" title="~/gate" label="The Go gate example prints an outcome and its reason">
The program prints **allow**, **review**, or **escalate**, with the
reason. "Clean up the drafts" is ambiguous, so the model may answer
`none`.
</Terminal>

The program judges the operation and never runs it. Your application
decides what each outcome does.
