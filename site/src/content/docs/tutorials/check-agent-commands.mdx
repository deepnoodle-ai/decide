An agent in a loop runs whatever shell command it decides on. Here you put
decide in front of it, so a command that could do lasting harm waits for a
person.

<Goal answer="! severe  yes">
<Fragment slot="end">
`checked.sh` in your project. It runs a command only when `command-risk`
flags nothing, so an agent or a script can call it in place of `sh -c`.
</Fragment>
<Fragment slot="need">
- decide, [installed](/start/#install-decide)
- An API key: [get one](/start/#get-a-key)
</Fragment>
</Goal>

<Steps>

1. ## Ask about two commands

   `command-risk` asks four yes-or-no questions about each line: could the
   command destroy work, leak a secret, publish or deploy something, or
   cause severe harm beyond your checkout? Try it on two commands that
   delete things:

   <Terminal tape="commands-ask" title="~" label="decide flags both commands as destructive, and only rm -rf ~/ as severe">
   **Both are flagged as destructive. Only `rm -rf ~/` is severe.** A hard
   reset loses local work, but it stays inside your checkout. Your
   percentages may differ a little.
   </Terminal>

   decide only reads the text. It never runs the commands it judges.

2. ## Write the script

   Save this as `checked.sh` and make it executable with
   `chmod +x checked.sh`:

   <Code code={checked} lang="sh" title="checked.sh" />

   `--fail-on flagged` makes decide exit with code 2 when an answer is
   flagged. The script runs the command on 0, refuses it on 2, and refuses
   it on 1 too, which means decide could not answer, such as when the key
   is wrong. To run the command anyway in that case, change the last line
   to run it.

3. ## Check that it works

   Run a harmless command, then a force push, and print the exit code:

   <Terminal tape="commands-check" title="~" label="checked.sh runs echo it ran, and refuses git push --force origin main with exit code 2">
   **The force push is refused, with exit code 2.** It is flagged on
   destructive and severe, so the push never starts. The harmless echo,
   just before it, ran.
   </Terminal>

   To flag only the worst commands, read `severe` alone with `--json`, as
   the Claude Code plugin does. A deploy is flagged on `publish`, so
   `checked.sh` refuses it too.

</Steps>
