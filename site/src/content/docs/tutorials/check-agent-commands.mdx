An agent in a loop runs whatever shell command it decides on. Here you put
decide in front of it, so a command that could do lasting harm waits for a
person. decide is a second check, and it can miss things.

You need decide [installed](/start/#install-decide) and an
[API key](/start/#get-a-key).

## Ask about two commands

`command-risk` asks whether a command could destroy work, leak a secret,
publish something, or cause severe harm. Try it on two commands that
delete things:

<Terminal tape="commands-ask" title="~" label="decide flags both commands as destructive, and only rm -rf ~/ as severe">
**Both are flagged as destructive. Only `rm -rf ~/` is severe.** A hard
reset loses local work, but it stays inside your checkout.
</Terminal>

decide only reads the command. It never runs it.

## Check that it works

Run a harmless command, then a force push:

<Terminal tape="commands-check" title="~" label="checked.sh runs echo it ran, and refuses git push --force origin main with exit code 2">
**The force push is refused, with exit code 2.** The echo before it ran.
</Terminal>

An agent or a script can now call `checked.sh` in place of `sh -c`.
