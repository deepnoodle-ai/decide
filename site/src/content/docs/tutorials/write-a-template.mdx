Your support team has a question no built-in template asks: which tickets
describe a billing mistake that needs a refund? Here you write a template
that asks it about every ticket.

You need decide [installed](/start/#install-decide) and an
[API key](/start/#get-a-key).

## Create a project template

```sh
mkdir support && cd support
decide templates new refund-check --project
```

`--project` puts the template in `.decide/templates/refund-check`, where
you can commit it.

## Make it useful for your team

Two tickets show that the template runs. To learn how often it's right,
run it on tickets you've already labeled. Where it's wrong, change the
question or the threshold.
