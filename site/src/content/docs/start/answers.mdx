A **decision model** answers a question with yes or no, a choice, or a
score. It writes no text. Each answer comes with its probability, so a
script can act on it with nothing to parse.

<AnswerTypes />

## Templates, items, and runs

- A **template** is a named set of questions. `decide templates` lists the
  built-in ones.
- An **item** is one thing the questions are asked about, such as a file,
  a changed function, or a line of text.
- A **run** is one template asked about your data. Every run is saved, and
  `decide runs view` shows it again.

## Flags

A template can **flag** the answers that need attention, such as a file
that is probably risky. A flagged answer is red and marked with `!`. Add
`--fail-on flagged` to exit with code 2 when anything is flagged.

`decide templates show TEMPLATE` shows a template's questions and when
each one is flagged.

## Models

decide runs on Jev, Clef, GPT-6 Luna, and Gemini Decision, with the same
commands and templates. [Providers](/reference/providers/) shows how to
choose one.
