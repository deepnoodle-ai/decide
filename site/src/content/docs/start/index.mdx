decide asks a decision model questions about your data. A decision model
answers with yes or no, a choice, or a score, each with its probability,
and writes no text.

## Install decide

<Tabs syncKey="install">
<TabItem label="Homebrew">
```sh
brew install deepnoodle-ai/tap/decide
```
</TabItem>
<TabItem label="Go">
```sh
go install github.com/deepnoodle-ai/decide/cmd/decide@latest
```
</TabItem>
<TabItem label="Download">
Download a binary for Linux, macOS, or Windows from the
[releases](https://github.com/deepnoodle-ai/decide/releases), and put it
on your `PATH`.
</TabItem>
</Tabs>

`decide --version` prints the version you have.

## Get a key

Pick one provider and export its key:

<Tabs syncKey="provider">
<TabItem label="Jev">
Jev by TypeSafe is the default. Get a key at
[typesafe.ai](https://typesafe.ai).
```sh
export TYPESAFE_API_KEY=...
```
</TabItem>
<TabItem label="Clef">
Clef runs on Cloudflare Workers AI. Create an API token that can use
Workers AI in the
[Cloudflare dashboard](https://developers.cloudflare.com/workers-ai/get-started/rest-api/).
```sh
export CLOUDFLARE_AUTH_TOKEN=...
export CLOUDFLARE_ACCOUNT_ID=...
export DECIDE_PROVIDER=cloudflare
```
</TabItem>
<TabItem label="GPT-6 Luna">
GPT-6 Luna runs on OpenAI's Decisions API, in beta. Create a key in the
[OpenAI platform](https://platform.openai.com/api-keys).
```sh
export OPENAI_API_KEY=...
export DECIDE_PROVIDER=openai
```
</TabItem>
<TabItem label="Gemini Decision">
Gemini Decision runs on Google's Gemini Decisions API, in beta. Create a
key in [Google AI Studio](https://aistudio.google.com/apikey).
```sh
export GEMINI_API_KEY=...
export DECIDE_PROVIDER=gemini
```
</TabItem>
</Tabs>

`decide models` checks that the key works. decide sends what it asks
about, such as your diff or a file you name, to the provider you chose.

## Ask about one line

Pipe in a line of text and run the built-in `sentiment` template:

<Terminal tape="start-line" title="~" label="decide answers positive about one line of text">
**The answer is positive**, with its probability. Your percentage may
differ a little.
</Terminal>

## Ask about your own changes

In a git repository with unstaged changes, judge each changed file:

<Terminal tape="start-diff" title="~/shop" label="decide flags billing/refund.go as a risk">
**`billing/refund.go` is flagged as a risk.** This
recording is from the demo's shop repository.
</Terminal>

<Aside type="tip">
`git diff` shows unstaged changes. Use `git diff HEAD` to include staged
ones. If nothing has changed, try `git diff HEAD~1`.
</Aside>

`code-risk` asks whether each file could cause security or data
problems, and how maintainable it is. A flagged answer is red and marked
with `!`.

To make a script or CI act on the answers, add `--fail-on flagged`. decide
then exits with code 2 when anything is flagged:

```sh
git diff | decide run code-risk --fail-on flagged
```

## Ask about a screenshot, recording, or PDF

Name an image, audio, video, or PDF file, and any template asks its
questions about it. Each file is one item. Jev reads text only, so choose
a provider that reads the file:

```sh
decide run code-risk diff.png --provider openai
decide run sentiment call.mp3 --provider gemini
```

Clef, GPT-6 Luna, and Gemini Decision read images. Only Gemini Decision
reads audio, video, and PDFs. If your provider can't read a file, decide
stops before it sends anything and names the providers that can. See
[Images, audio, video, and PDFs](/reference/items/#images-audio-video-and-pdfs).
